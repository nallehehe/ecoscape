# Ecoscape 
Fullstack - Fullstack Airbnb-style Platform for Ecotourism.

EcoScape is a fullstack web application built as a group project across multiple courses. Our goal was to create an Airbnb-style platform with a focus on sustainable and eco-friendly tourism, promoting responsible travel and green accommodations.

## My Role

During the project I primarily acted as the scrum master and during development focused on users & host, token based authentication (JWT) and documented our API.
